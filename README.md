# 📋 열린 게시판 (Simple Bulletin Board)

사용자와 관리자를 명확하게 구분하고, 작성일과 조회수 등을 직관적인 표(목록) 형태로 한눈에 쉽게 확인할 수 있도록 최적화된 **단순 게시판 웹 애플리케이션**입니다.

---

## ✨ 핵심 특징 및 개선 사항

### 1. 사용자와 관리자 역할 명확 구분
- **시각적 뱃지 구분**:
  - 관리자 작성 글 및 댓글: `👑 관리자` (보라색/강조 뱃지)
  - 일반 사용자 작성 글 및 댓글: `👤 사용자명` (직관적인 뱃지)
- **역할별 탭 필터링**:
  - `전체 글` / `👑 관리자 글(공지)` / `👤 사용자 글` 탭으로 원하는 글만 모아보기
- **권한 차등화**:
  - **일반 사용자**: 글 작성 시 원하는 작성자명과 4~8자리 간이 비밀번호(PIN)를 설정하여 본인 글 수정/삭제
  - **관리자 (마스터 비번: `admin1234`)**:
    - 로그인 시 상단에 '👑 관리자 모드' 활성화
    - **📌 공지사항 상단 고정** 등록 및 해제 기능
    - 전체 게시글 및 댓글 강제 수정/삭제 권한
    - 비밀글 즉시 열람 권한

### 2. 날짜와 조회수를 한눈에 쉽게 확인하는 레이아웃
- **클래식 & 모던 목록형 테이블(Table View) 기본 제공**:
  - `번호 | 분류 | 제목 (+댓글수) | 작성자 | 작성일 | 조회수 | 추천수`가 줄별로 일목요연하게 정렬
  - **작성일 가독성 최적화**: 오늘 작성된 글은 `HH:mm` (예: 15:20), 이전 글은 `YYYY.MM.DD` (예: 2026.11.10)로 표시되며 마우스 오버 시 전체 일시 확인 가능
  - **조회수 및 추천수 명확화**: 각 글의 관심도와 열람수를 표에서 즉시 비교 가능
- **뷰 전환 지원**: `📋 목록형(표)` ↔ `🗂️ 카드형(요약)` 토글 지원

### 3. 직관적인 소통 & 편의 기능
- **공지사항 최상단 고정**: `📌 공지` 뱃지와 은은한 하이라이트 배경으로 중요 공지가 묻히지 않도록 최상단 고정
- **익명/실명 유연한 댓글**: 사용자와 관리자 모두 자유롭게 댓글 소통 가능
- **추천(공감) 기능**: 마음에 드는 글에 추천(❤️) 기능 제공 (중복 방지)
- **상세 검색 및 카테고리 필터**: 제목, 내용, 작성자 통합 검색 및 분류(`공지`, `일반`, `질문`, `건의`, `정보`)

## 🛠️ 기술 스택

- **런타임**: Node.js (v20+ 이상, 내장 `node:sqlite` 활용)
- **백엔드**: Express.js
- **데이터베이스**: SQLite (`complaints.db`, 자동 스키마 마이그레이션)
- **프론트엔드**: HTML5, Vanilla JavaScript, CSS3 (모던 반응형 디자인)
